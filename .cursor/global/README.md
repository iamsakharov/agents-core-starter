# `.cursor/global/` — источник истины глобального окружения Cursor

Это **дом Cursor** для глобальной конфигурации. В отличие от Claude, у Cursor **нет файлового
авто-подхвата** глобальных правил из репо: глобальный слой Cursor задаётся в приложении —
**Cursor Settings → Rules → User Rules** (и в глобальных настройках/Memories).

Поэтому здесь лежит не авто-устанавливаемый конфиг, а **источник истины текста**, который должен быть
внесён в Cursor User Rules, чтобы Cursor был always-on во всех папках (паритет с глобальным Claude).

## Что здесь лежит

| Файл | Роль |
|------|------|
| `USER-RULES.md` | Текст для вставки в Cursor **User Rules** — компактный always-on слой + указатель на дисциплину репо. |

## Расхождение, которое нужно закрыть

Сейчас у Cursor правила (`.cursor/rules/*.mdc`) и скилы применяются **пер-проектно** (вендоринг в каждый
репо) — внутри проекта всё работает, но в произвольной папке вне вендоренного проекта дисциплины нет.
Claude уже сделан **глобальным** (`~/.claude`). Чтобы прийти в соответствие, Cursor-агент должен внести
`USER-RULES.md` в User Rules и/или гарантировать, что все рабочие папки вендорятся.

Установка глобального профиля (симлинки + User Rules):

```bash
bash scripts/install-cursor-global.sh
```

Проверка синхронности — `bash scripts/check-parity.sh`.
Парный дом Claude — [`.claude/global/`](../../.claude/global) (+ `scripts/install-global.sh`).
