# quickstart

Этот skill — точка входа для новой задачи.

Используй его когда:
- пользователь описывает новую цель или задачу
- нет существующего плана, roadmap item или структуры
- нужно с нуля начать работу над чем-то новым
- пользователь написал "начинаем", "хочу сделать", "нужно построить" или просто описал задачу

## Что делать немедленно

Не начинать implementation. Не задавать много вопросов. Не строить догадки.

**Действие:** Запустить `plan-orchestrator` subagent.

Передать ему:
- описание задачи от пользователя (дословно)
- контекст проекта (если есть: язык, стек, roadmap/_status.md если существует)
- запрос: разложить на этапы, определить волны, подготовить отдельные prompts

## Что plan-orchestrator должен вернуть

- Продуктовый смысл задачи
- Этапы с зависимостями
- Routing по subagent types
- Отдельный prompt для каждого этапа
- Риски и пробелы
- Рекомендуемый следующий шаг

## После получения плана

1. Показать план пользователю компактно
2. Спросить: "Всё верно? Начинаем с этапа 1?"
3. После подтверждения → запустить первый этап через нужный subagent
4. После этапа → запустить `reviewer`
5. Получить апрув → следующий этап или refinement

## Что запрещено

- не начинать implementation без плана
- не делать giant one-shot run
- не пропускать plan-orchestrator
- не смешивать planning и execution в одном шаге
- не считать задачу понятной без структуры

## Формат поведения

задача от пользователя →
plan-orchestrator →
план показан пользователю →
подтверждение →
этап 1 → review → апрув → этап 2 → ...
