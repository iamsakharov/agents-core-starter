## Как работать с roadmap

1. Новый эпик → создать файл в `epics/`, добавить строку в таблицу выше.
2. Новая задача → создать файл в `tasks/`, привязать к эпику.
3. Статус задачи → обновлять в файле задачи и в `_status.md`.
4. Завершённый эпик → перенести в таблицу «Завершённые», зафиксировать дату.
