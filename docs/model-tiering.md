# Модельная иерархия (model tiering)

Единый принцип для обоих окружений: **сильные старшие модели ведут мышление (планирование,
архитектура, review, глубокий разбор); младшие модели выполняют рутину (статус, lookup,
механические операции).** Так дорогой intelligence тратится там, где он двигает результат,
а рутина не жжёт бюджет.

## Политика по агентам

| Агент | Роль | Тир | Claude Code (`model:`) |
|-------|------|-----|------------------------|
| `plan-orchestrator` | декомпозиция крупной задачи в план | senior | `opus` |
| `epic-master` | стратегический контекст эпика, зависимости, риски | senior | `opus` |
| `roadmap-task-analyzer` | глубокий разбор item → execution-ready | senior | `opus` |
| `reviewer` | суждение о качестве/архитектуре | senior | `opus` |
| `refinement-agent` | структурирование замечаний в итерацию (readonly) | mid | `sonnet` |
| `roadmap-task-status` | чтение статуса и отчёт (рутина) | routine | `haiku` |

**Главный цикл** (сам Claude Code / основной агент Cursor) держи на сильной модели — он ведёт
планирование и оркестрацию верхнего уровня. Рутину он делегирует младшим субагентам по таблице.

## Реализация

- **Claude Code** — тир задан в `model:` каждого `.claude/agents/*.md`. Алиасы `opus`/`sonnet`/`haiku`
  **версионно-стабильны**: не требуют правок при выходе новых версий моделей. Работает из коробки.
- **Cursor** — субагенты `.cursor/agents/*.md` стоят на `model: inherit` (наследуют сильную модель
  главного цикла). Cursor принимает в поле `model` только `inherit` или **конкретный version-ID**
  (`auto` невалиден), а точные ID Claude-моделей не версионно-стабильны и при опечатке **молча
  игнорируются**. Поэтому тир на стороне Cursor применяется одним из двух способов:
  1. оставить `inherit` (безопасный дефолт — рутинные агенты наследуют модель сессии), **либо**
  2. выставить `model` каждого субагента точным ID из палитры моделей Cursor
     (senior → Opus 4.8, mid → Sonnet 5, routine → Haiku 4.5), сверив строку с UI, чтобы не попасть
     в «молча проигнорировано».

  Источник: [Cursor Subagents](https://cursor.com/docs/subagents), [Models](https://cursor.com/docs/models).

## Почему не хардкодим Claude-ID в `.cursor/agents`

Version-специфичные строки (`claude-opus-4.8` и т.п.) в пропагируемом источнике истины пришлось бы
править в каждом агенте при каждом релизе модели — это ровно тот дрейф, против которого построен
слой. Claude-алиасы такого не требуют; Cursor стабильного алиаса для субагентов не даёт, поэтому там
тир — осознанный ручной выбор, а не захардкоженная строка.
